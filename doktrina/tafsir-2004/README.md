# «Тафсири Кодекси меҳнати Ҷумҳурии Тоҷикистон» (2004): комментарий к ТК 1997 г.

**Худоёров Б. Т., Шонасридинов Н., Муқумова С. А.** Тафсири Кодекси меҳнати Ҷумҳурии Тоҷикистон /
масъул муҳаррир Н. Шонасридинов. — Душанбе: ЭР-граф, 2004. — 480 с. (Таджикский национальный университет,
юридический факультет; издание при поддержке Швейцарского бюро по сотрудничеству.)

**Статус: историческая доктрина, не норма.** Книга комментирует **Трудовой кодекс 1997 г.** (Закон РТ от 15.05.1997 № 417),
который **отменён ст. 365 ТК 2016 г.** Нумерация статей другая (старая ст. 97 — оплата отпуска, нынешняя ст. 97 —
отпуск за особый характер работы). Норму, сумму, срок, возраст и название органа брать только из действующего ТК
(`kodeks/`) и актов (`akty/tekst/`); комментарий — для толкования, аргументов и вопросов к фактам, отдельным
блоком с пометкой «по комментарию 2004 г. к ТК 1997 г.». Не путать с «Тафсир» 2019 г. к ТК 2016 г. (в реестре — только карточка).

## Откуда и что здесь

Пакет «Tafsir-2004-AI-Pack» прислан пользователем 21.10.2026. Его подготовил другой ИИ по PDF пользователя
(`tafsiri_kodeksi_mehnat 2004.pdf`, SHA-256 `cbbc0f10…a725` — `SOURCE_MANIFEST.json`): 457 страниц электронного файла
(в выходных данных — 480 печатных), таджикский текст восстановлен из старых шрифтов в Unicode
(36 534 исправленных знака). Архив пришёл **обрезанным**: нет оригинального PDF, служебных скриптов, `data/topics.json`
и конца `data/pages.jsonl`; остальные файлы сверены с описью пакета по SHA-256.

| Файл | Что это |
|---|---|
| `FULL_TEXT_TG.md` | Весь текст книги на таджикском, 457 страниц, якоря `pdf-page-NNN`, заголовки `## PDF page N` |
| `ARTICLE_INDEX.md` | 265 статей старого ТК → страницы PDF (ссылки ведут на якоря в `FULL_TEXT_TG.md`) |

## Как искать и цитировать

- По статье старого ТК: `grep -n "^Моддаи 108/4\." doktrina/tafsir-2004/FULL_TEXT_TG.md` (или найти страницы в `ARTICLE_INDEX.md`).
- По теме — таджикские слова: `grep -n -i "фонди захиравии\|мӯҳлати санҷиш\|ихтисор" doktrina/tafsir-2004/FULL_TEXT_TG.md`.
- Ссылка: «Худоёров Б. Т. и др. Тафсири Кодекси меҳнати ҶТ (2004), комм. к ст. … ТК 1997 г., PDF с. …» —
  **страницы электронного файла**, не печатного издания (оглавление книги даёт другие номера).
- Ограничения источника: заголовки 28 и 104 встречаются дважды (второй 104 — государственные тарифы, PDF с. 217),
  заголовков 90–92 в теле нет; опечатки оригинала сохранены. Для важной цифры — перепроверить по PDF пользователя.

## Что книга даёт по нашим пробелам (проверено по тексту)

- **Ст. 97 ТК 2016 (особый характер работы)** ↔ старая ст. 88, PDF с. 186: авторы пишут, что перечень профессий
  Правительство **тогда (2004) не определило**. Это не доказательство пробела в 2026 г. — см. ПП № 521 в ред. ПП № 567.
- **Ст. 146 (тарифы)** ↔ второй заголовок «Моддаи 104. Тарифҳои давлатӣ…», PDF с. 217: исторические пояснения о тарифах
  для **бюджетных** организаций; действующей сетки не даёт.
- **Ст. 162 (резервный фонд зарплаты)** ↔ старая ст. 108/4, PDF с. 239–240. В старом кодексе была часть, которой в
  нынешней ст. 162 нет: «Фонди захиравии музди меҳнати ташкилотҳои гайрибуҷетӣ [так в источнике] дар оинномаи онҳо муқаррар карда
  мешавад» — **резервный фонд небюджетных организаций устанавливался в их уставе**. Для частного работодателя это
  аргумент закрыть пробел ст. 162 своим уставом / коллективным договором / ЛНА (ч. 4 ст. 12 ТК), пока Правительство
  не утвердило порядок. Цифра 0,5 % на той же странице — резервный фонд **местных бюджетов** (Закон о госфинансах 2002 г.),
  к фонду зарплаты работодателя не относится.

# Трудовой кодекс РТ — база для HR-кейсов

Трудовой кодекс Республики Таджикистан от 23.07.2016 № 1329
(ред. по состоянию на 17.06.2026), разобранный в Markdown для работы с Claude.

- `kodeks/INDEX.md` — оглавление (41 глава, 367 статей)
- `kodeks/glava-NN.md` — текст по главам, статьи — заголовки `## Статья N. ...`
- `CLAUDE.md` — как Claude разбирает кейсы: поиск норм, формат ответа, навигатор «тема → статьи»
- `cases/` — сохранённые кейсы (шаблон `cases/_template.md`)
- `akty/` — подзаконные и смежные акты: реестр `akty/REESTR.md` и тексты `akty/tekst/` (в т.ч. расчёт доплат, чек-лист инспекции труда, выдержка из КоАП)
- `doktrina/` — учебник по трудовому праву РТ (РТСУ, 2020), памятка ICNL «ТД vs ГПД»
- `chek-list/` — печатный чек-лист самопроверки работодателя (PDF + HTML-исходник; PDF пересобирается: `chrome --headless --print-to-pdf`)
- `shablony/` — шаблоны кадровых документов (.docx): заявления, приказы
- `source/` — исходный .docx кодекса

## Обновление редакции

Пришлите новый .docx кодекса в чат — Claude пересоберёт `kodeks/` (скрипты сборки из репозитория убраны 21.10.2026,
при необходимости их можно вернуть из истории git).
